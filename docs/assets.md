# Capas e referência

A referência do usuário é a composição com cinco telas do MapRun, enviada em 21/09/2026. Ela orienta a UI; não é incorporada como screenshot dentro do produto.

- `public/images/mantiqueira-run.png`: arte editorial ilustrativa gerada uma única vez pela ferramenta integrada ImageGen. Não representa uma prova ou local verificado. Reutilizável, sem gerar uma imagem por evento.

- `public/images/runners.jpg`: Unsplash, https://images.unsplash.com/photo-1461896836934-ffe607ba8211 — atleta em pista; fallback de rua.
